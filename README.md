# Android Phone UI

An interactive Android-inspired phone interface built with Next.js and designed for both mobile and desktop browsers.

## Features

- Lock screen and live clock
- Android-style home screen, app drawer, status and navigation bars
- Quick settings with working Wi-Fi, Bluetooth, sound, flashlight and brightness controls
- Interactive Calculator, Clock, Notes, Settings, Calendar and Browser
- Phone, Messages, Camera, Photos and Music interface demos
- Persistent notes, theme switching and three wallpapers
- Full-screen mobile layout and framed desktop presentation

## Development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```
